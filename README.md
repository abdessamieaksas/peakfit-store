# Peakfit Store

Peakfit is a mobile-first Moroccan performance-wear commerce platform. The store is designed around reusable, data-driven catalog and product templates, Cash on Delivery ordering, operational order management, and marketing attribution.

The production foundation will use Next.js, TypeScript, Tailwind CSS, Supabase PostgreSQL, Supabase Storage, and Vercel.

## Status

Repository initialized. Phase 1 foundation work follows in subsequent commits.
